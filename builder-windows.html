VoipAppz Builder

Install VoipAppz Builder on Windows and make your first change

VoipAppz Builder is a desktop app for changing your VoipAppz admin and user screens through chat. You describe a change; a coding agent (Claude Code, on your own Claude account) edits a private copy of the VoipAppz React app on your computer, and the result shows in Admin and User previews next to the chat. Your own checkout is never touched.

Builder is a pre-release for developers. The installer is not code-signed yet and has no automatic updates.

Download from Builder releases

Before you start

  • Windows 10 or 11, 64-bit, with internet access for the first run.
  • A Git checkout of the VoipAppz React app (voipappz/app) on this computer. Builder makes its own worktree next to it, named <app folder>-builder, on the branch builder/work.
  • Claude Code installed and signed in on this computer (run claude once in a terminal). The agent runs on your Claude account.
  • A VoipAppz account on https://switch.voipappz.io to sign in to the previews. Node.js is not required: Builder installs the version the app needs.

Install

  1. Download VoipAppz.Builder_0.1.2_x64-setup.exe from the Builder releases page.
  2. Run it. If Windows shows Windows protected your PC, select More info, then Run anyway: the installer is not signed yet.
  3. Start VoipAppz Builder from the Start menu. It runs from the system tray and opens a setup window.

First start

  1. Under React app, choose the folder of your voipappz/app Git checkout.
  2. Leave the API address as https://switch.voipappz.io, or enter another HTTPS address.
  3. Optional: enter your API email and password so the agent gets read-only platform tools (extensions, numbers, call logs). Leave both empty to skip; you can still sign in to the previews.
  4. Select Check. You should see API is reachable.
  5. Select Start. The window shows each step: installing Node, installing the app's packages, starting the app, starting the agent. The first run can take several minutes; later starts are quick.
  6. When setup finishes, your browser opens the Builder page: chat on one side, Admin and User previews on the other. Sign in to each preview with your VoipAppz account.

Make your first change

  1. In the chat, describe the change, for example: Add a search field above the extensions table.
  2. The agent reads the app's source and edits it. Edits inside the Builder worktree are applied without asking; a command the agent wants to run (for example a test) asks for your permission first.
  3. The previews reload on their own. Check the Admin preview, then ask for a refinement or say what to undo.
  4. Your changes are files in the Builder worktree, on its builder/work branch. Review them with Git, then commit and push or merge them as you would any branch.

What Builder can and cannot do

  • It edits only the React app in its own worktree. It cannot write outside that folder, inside .git, or through links that lead out.
  • The platform API is read-only for the agent: it can list extensions, numbers and calls, but not create, change or delete them. Make those changes in the admin portal.
  • Deploying the changed app to your live environment is not part of Builder yet.

Where things are

  • Settings: %APPDATA%\voipappz-builder\builder.toml.
  • Logs: %LOCALAPPDATA%\voipappz-builder\builder.log and app.log (the app's dev server).
  • Tray menu: Open VoipAppz Builder, Connect App and API…, Settings, View Logs, Restart, Quit VoipAppz Builder. Closing the setup window leaves Builder running in the tray.

If it doesn't work

  • “Use an HTTPS API address” means the API address is not https://. Only localhost may use plain http://.
  • “Could not reach the API” means the address does not answer. Check it in a browser and check your internet connection.
  • Setup stops with an error: the window keeps the details and the log location. Select Copy details and send them with your support ticket.
  • The chat does not answer: make sure Claude Code is signed in (claude in a terminal) and that your Claude account has quota left.
  • The previews are empty: another program may be using port 3000. Stop it and restart Builder from the tray.
